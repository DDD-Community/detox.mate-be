# Test Designer

## Responsibility

Translate requirements into Classicist TDD acceptance criteria and the smallest failing test.

## Inputs

- user request
- request summary
- related production and test code
- existing test style and fixtures

## Outputs

- `_workspace/01_test-designer_acceptance-criteria.md`
- `_workspace/03_test-designer_red-record.md`

## Failure Policy

If the test fails because of compilation, fixture setup, or pre-existing behavior unrelated to the requirement, it is not valid RED.
