== User API

=== Get My Profile

`GET /users/me`는 `id`, `displayName`, `userCode`, `profileImageUrl`, `pushNotificationEnabled`를 반환한다.
`userCode`는 친구 검색에 사용하는 5자리 코드다. 알림을 끄면 `pushNotificationEnabled`는 `false`다.
모든 응답 키는 항상 포함되며, 프로필 이미지가 없으면 `profileImageUrl`은 `null`이다.
사용자 코드가 없는 기존 데이터는 폐기 대상이며 백필하지 않는다.

operation::users/me-get[snippets='http-request,request-headers,http-response,response-fields']
operation::users/me-get-unauthorized[snippets='http-request,request-headers,http-response,response-fields']

=== Update My Profile

`PATCH /users/me`의 한 요청 본문에 `displayName`과 `profileImageObjectKey`를 함께 보내면 두 값을 함께 수정한다.
닉네임은 공백 포함 1자 이상 10자 이하이며, `displayName`을 생략하면 기존 값을 유지한다.
`profileImageObjectKey`를 생략하면 기존 이미지를 유지하고, 명시적으로 `null`을 보내면 이미지를 제거한다.
다른 사용자의 이미지 경로 등 잘못된 요청은 두 값을 모두 변경하지 않는다.
응답은 조회와 같은 다섯 필드이며 `userCode`는 프로필 수정으로 변경되지 않는다.

operation::users/me-patch[snippets='http-request,request-headers,request-fields,http-response,response-fields']

== Friend API

=== Get My Friend Invite Code

`code`는 Airbridge 링크 생성과 `GET /friends/invite/{code}` 조회에 사용하는 기존 64자리 링크용 코드다.
`userCode`는 같은 사용자의 5자리 검색용 코드이며 공유 문구의 “초대 코드”에 사용한다.
두 필드는 항상 포함되며 `null`이 아니다. 이메일은 반환하지 않는다.

== Transfer Phrase API

=== Get a Random Transfer Phrase

`GET /transfer-phrases/random`은 로그인한 사용자가 제한 시간 변경 화면에서 필사할 문장 하나를 조회한다.
요청 본문은 없으며, DB에 저장된 문장 전체를 `phrase` 필드로 반환한다.
매 요청마다 독립적으로 선택하므로 같은 문장이 연속으로 나올 수 있다.
성공 응답에는 `Cache-Control: no-store`를 설정한다.
등록된 문장이 없으면 `404 NOT_FOUND`, 인증이 유효하지 않으면 `401 UNAUTHORIZED`를 반환한다.
필사 일치 여부와 버튼 활성화는 프론트에서 처리하며, 이 조회는 잠금 시간 설정을 변경하지 않는다.

operation::transfer-phrases/random[snippets='http-request,request-headers,http-response,response-fields']

=== Manual Catalog Setup

dev/prod는 `ddl-auto: validate`이므로 배포 전에 `db/manual/2026-10-05-transfer-phrase.sql`로 테이블을 생성한다.
이미 `transfer_phrase` 테이블이 있다면 스키마와 데이터를 먼저 확인하고 기존 테이블을 보존한다.
문장 모음은 운영자가 `transfer_phrase.transfer_phrase`에 수동으로 입력한다. `id`는 자동 생성된다.
문장은 최대 255자이며 NULL은 허용하지 않는다. 공백만 있는 값은 등록하지 않는다.
저자 표기가 필요하면 같은 문자열에 포함한다. API는 공백, 줄바꿈, 문장 부호를 포함한 저장값을 그대로 반환한다.
자동 데이터 삽입이나 문장 등록·수정·삭제 API는 제공하지 않는다.
